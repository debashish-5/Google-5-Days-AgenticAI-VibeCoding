The provided text describes the structure and usage of Agent Skills, which is a system for organizing and executing reusable tasks or workflows within an AI agent. Here's a summary of the key points:

1. Agent Skills are organized into folders that include a `SKILL.md` file (metadata), scripts, references, and assets. These components can be loaded as needed without polluting the token window.
2. The `SKILL.md` file contains metadata about the skill, including its name and description, which is used to activate the skill based on specific triggers.
3. Scripts contain executable code for deterministic tasks, while references and assets provide supplementary context and templates.
4. Skills can be either created by translating existing knowledge or crystallizing a workflow that an AI agent has already performed successfully.
5. To test the skill, it is dropped into the appropriate directory for your tool, restarted, and tested with natural prompts to confirm if it triggers correctly.
6. There are three main ways to interact with and install Skills: file-based (Coding Agents & CLIs), UI-based (Web & Enterprise Workspaces), and programmatic (Custom Frameworks).
7. It's important to note that while the format for Agent Skills is shared, the installation path, activation rules, and tool-specific details may vary depending on the specific AI agent or chatbot being used.
